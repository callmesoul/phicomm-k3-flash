## 条目模板

复制以下内容新建 `<固件>-<版本>.md`：

```markdown
# <固件> <版本>

## 基本信息
- **固件文件**：<文件名.trx>
- **下载链接**：<官方/原作者链接>
- **sha256**：<校验值>
- **刷入方式**：CFE + TFTP do.htm（见 ../../flashing-guide.md）
- **测试日期**：YYYY-MM-DD
- **记录人**：<GitHub 用户名或"社区实测">

## 实测结果
- **CFE 刷入**：✅/❌（备注）
- **启动**：✅/❌（首次启动耗时）
- **LAN**：✅/❌
- **WAN（DHCP）**：✅/❌
- **WAN（PPPoE）**：✅/❌/未测
- **2.4G WiFi**：✅/❌（备注：ACS/clm_blob/信道）
- **5G WiFi**：✅/❌（备注：支持的信道范围）
- **稳定性**：✅/⚠️/❌（连续运行时长、客户端数、已知断连场景）

## 坑
- 引用 ../../pitfalls.md 中适用的条目，或列出本版本特有坑（现象→原因→解决）

## 备注
- <其他值得记录的：性能、温度、功耗、与特定光猫的兼容性等>
```

## 字段说明

- **刷入方式**：目前实测有效的只有 CFE + TFTP `do.htm` 一种；如果你找到了新路子，在 flashing-guide.md 更新并在这里注明
- **总体状态**：✅ 可用 / ⚠️ 部分功能受限 / ❌ 不推荐
- 没测的字段写"未测"，**不要凭印象填**
